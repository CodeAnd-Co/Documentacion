# RF33: Usuario elimina plantilla de reporte.

### Historia de Usuario

Yo como usuario quiero eliminar plantillas de reporte que ya no necesito para mantener organizada mi lista de plantillas 

  **Criterios de Aceptación:**
  - El usuario debe de poder seleccionar y eliminar alguna de las plantillas guardadas.
  - La plantilla debe de desaparecer de la lista.
  - El sistema debe de solicitar confirmación antes de la eliminación.
  - La plantilla se elimina de la base de datos.
  - Se muestra un mensaje de confirmación al eliminar la plantilla exitosamente.
  - Se muestra un mensaje de error si la eliminación no es exitosa.
  - Se muestra un mensaje de error si hay un fallo de red, conexión o servidor.

### Aplicación local

``` mermaid
sequenceDiagram
    actor Usuario
    participant vista as consultarPlantilla.ejs
    participant utilPlantilla as moduloPlantillas.js
    participant casoUso as eliminarPlantilla.js
    participant plantillaAPI as eliminarPlantillasAPI.js
    participant server as BackendDesacoplado

    activate Usuario
    Usuario ->> vista: Consulta la vista
    activate vista
    vista ->> utilPlantilla: Click en botón eliminar
    deactivate vista
    activate utilPlantilla
    utilPlantilla -) casoUso: eliminarPlantilla()
    deactivate utilPlantilla
    activate casoUso
    casoUso -) plantillaAPI: eliminarPlantillaAPI()
    
    activate plantillaAPI
    plantillaAPI -) server: eliminarPlantillaAPI()
    activate server 
    server -->> plantillaAPI: response(exito)
    deactivate server
    plantillaAPI -->> casoUso: response(exito)
    deactivate plantillaAPI
    casoUso -->> utilPlantilla: response(exito)
    deactivate casoUso
    activate utilPlantilla
    utilPlantilla -->> vista: response(exito)
    deactivate utilPlantilla
    activate vista
    vista ->> Usuario: 'Mensaje de exito'
    deactivate vista
    deactivate Usuario


```

### Backend Desacoplado

```mermaid
sequenceDiagram
  participant app as app.js
  participant indicePlantillas as plantillasIndice.rutas.js
  participant eliminarPlantillaRuta as eliminarPlantilla.ruta.js
  participant middlewares as Middlewares (verificarToken, verificarPermisos, checarPermisos)
  participant eliminarPlantillaControlador as eliminarPlantillaControlador.js
  participant repositorioEliminarPlantilla as repositorioEliminarPlantilla.js
  participant modeloEliminarPlantilla as modeloEliminarPlantilla.js
  participant DB as base de datos

  activate app
  app ->> indicePlantillas: /plantillasIndice
  activate indicePlantillas
  indicePlantillas ->> eliminarPlantillaRuta: DELETE/eliminar 
  deactivate indicePlantillas
  activate eliminarPlantillaRuta
  eliminarPlantillaRuta ->> eliminarPlantillaControlador: eliminarPlantillas()
  deactivate eliminarPlantillaRuta
  activate eliminarPlantillaControlador
  eliminarPlantillaControlador -) repositorioEliminarPlantilla: eliminarPlantillaRepositorio()
  activate repositorioEliminarPlantilla
  repositorioEliminarPlantilla -) modeloEliminarPlantilla: eliminarPlantilla()
  activate modeloEliminarPlantilla
  modeloEliminarPlantilla -) DB: query()
  activate DB
  alt Caso exitoso
    rect rgb(200, 255, 200)
    DB -->> modeloEliminarPlantilla: response.status(200).json(mensaje)
    modeloEliminarPlantilla -->> repositorioEliminarPlantilla: response.status(200).json(mensaje)
    repositorioEliminarPlantilla -->> eliminarPlantillaControlador: response.status(200).json(mensaje)
    eliminarPlantillaControlador -->> eliminarPlantillaRuta: response.status(200).json(mensaje)
    activate eliminarPlantillaRuta
    eliminarPlantillaRuta -->> app: response.status(200).json(mensaje)
    deactivate eliminarPlantillaRuta
    end
  else Falta id de plantilla
    rect rgb(255, 235, 238)
    DB -->> modeloEliminarPlantilla: response.status(400).json(mensaje)
    modeloEliminarPlantilla -->> repositorioEliminarPlantilla: response.status(400).json(mensaje)
    repositorioEliminarPlantilla -->> eliminarPlantillaControlador: response.status(400).json(mensaje)
    eliminarPlantillaControlador -->> eliminarPlantillaRuta: response.status(400).json(mensaje)
    activate eliminarPlantillaRuta
    eliminarPlantillaRuta -->> app: response.status(400).json(mensaje)
    deactivate eliminarPlantillaRuta
    end
  else Error de servidor
    rect rgb(255, 235, 238)
    DB -->> modeloEliminarPlantilla: response.status(500).json(mensaje)
    deactivate DB
    modeloEliminarPlantilla -->> repositorioEliminarPlantilla: response.status(500).json(mensaje)
    deactivate modeloEliminarPlantilla
    repositorioEliminarPlantilla -->> eliminarPlantillaControlador: response.status(500).json(mensaje)
    deactivate repositorioEliminarPlantilla
    eliminarPlantillaControlador -->> eliminarPlantillaRuta: response.status(500).json(mensaje)
    deactivate eliminarPlantillaControlador
    activate eliminarPlantillaRuta
    eliminarPlantillaRuta -->> app: response.status(500).json(mensaje)
    deactivate eliminarPlantillaRuta
    end
  end
  deactivate app
```
